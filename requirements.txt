Activity Tracker PoC - Requirements
===================================

Operating System:
- Windows 10 or Windows 11

Runtime / SDK:
- .NET 8 SDK

Programming Language:
- C#

NuGet Dependencies:
- Microsoft.Data.Sqlite

Windows API:
- user32.dll
- GetForegroundWindow
- GetWindowText
- GetWindowThreadProcessId

Development Environment:
- Visual Studio 2022 or Visual Studio Code
- PowerShell

Database:
- SQLite
- Database file: activity.db

Output:
- activity.db
- activity.csv

Project Type:
- .NET Console Application

Setup:
1. Open PowerShell.
2. Navigate to the project directory.
3. Run: dotnet restore
4. Run: dotnet build
5. Run: dotnet run

Important:
- The application is Windows-specific because it uses user32.dll.
- Microsoft.Data.Sqlite is restored through reflection.csproj.
- activity.db and activity.csv are generated by the application.
- The application checks activity periodically but saves data
  only when the active activity changes.
